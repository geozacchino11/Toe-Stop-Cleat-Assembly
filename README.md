# Toe Stop & Cleat Assembly — AutoCAD Project

A mechanical CAD drafting and assembly project featuring a **Toe Stop & Cleat Assembly**, created in **AutoCAD**. This repository includes individual component drawings, standard hardware fasteners, and the complete assembly sheet.

## Overview
This project focuses on multi-part mechanical drafting, layer management, tolerance alignment, and fastener hardware assembly. Each component is drafted in its own `.dwg` file and brought together in the master assembly drawing.

## Repository Contents

* **`ASSEMBLY DRAWING.dwg`** — Master assembly drawing showing how the toe stop base, cleat, pin, and fasteners fit together into the complete unit.
* **`TOE STOP BASE.dwg`** — Main structural housing/base component of the toe stop assembly.
* **`CLEAT.dwg`** — High-traction cleat component engineered to mate with the toe stop base.
* **`Cleat Pin.dwg`** — Cylindrical alignment/retention pin used to secure the cleat to the base.
* **`Hex Caqp screw.dwg`** — Hex cap screw fastener used to clamp and secure the mechanical assembly.
* **`acad (layer Hex Nut.dwg`** — Hexagonal nut drafted with structured AutoCAD layer organization to mate with the hex cap screw.
* **`Washer.dwg`** — Flat washer designed to distribute clamping load and prevent fastener loosening.

## Tools & Skills Demonstrated
* **Software:** AutoCAD
* **Skills:** Technical Drafting (`.dwg`), Layer Management, Mechanical Hardware & Fastener Detailing, Multi-Part Assembly Documentation
